# grème — AI Shopping App + Website

Build a complete production-ready shopping platform called **grème**.

The brand name must always appear exactly as **grème**, lowercase, including the `è`.

I need TWO working products from the same project:

1. A responsive website that anyone can open in a browser.
2. A real standalone Android shopping application that can eventually be built as an installable APK.

Do NOT build this as a simple demo or static mockup.

## Technology

Use a stable, maintainable architecture suitable for both web and Android.

Use:

* React Native
* Expo
* React Native Web
* Supabase
* JavaScript/TypeScript
* responsive layouts
* environment variables for secrets/configuration

The Android application must NOT require Expo Go to function after it is built.

The website and Android app must use the same Supabase backend.
